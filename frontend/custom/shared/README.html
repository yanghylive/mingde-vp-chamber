租户品牌与会员 UI 共享核心

同一份框架无关 JavaScript 核心，供 CRMEB Vue2 管理端和 UniApp 用户端复用品牌、资料、附件、认证与审核规则。

前端二开入口G1-01C 基线PRD

租户品牌接口

接口用途
normalizeTenantBrand(remote, defaults)解包常见 CRMEB 响应，兼容 camelCase/snake_case 字段，过滤危险 URL，并统一颜色格式。
bootstrapTenantBrand(options)调用注入的 fetchRemote；远端失败时返回默认品牌和可序列化错误，不阻断应用启动。
installTenantBrand(Vue, options)创建 Vue2 可响应状态并挂到 Vue.prototype.$tenantBrand；UniApp 当前同样使用 Vue2，可直接复用。

会员 UI 接口

接口组用途
profileFormFromData / buildProfilePatch资料响应转表单、列表/隐私规范化和白名单提交校验。
normalizeMemberAsset / proofAssetsFromApplication附件元数据、对象键、available 与认证材料展示的稳定适配。
buildVerificationSubmission班级、毕业时间、1–10 份材料和 supersedes 关系校验。
verificationStatusMeta / reviewActionsForStatus / buildReviewRequest用户/Admin 共用认证状态、合法审核动作和审核意见规则。
createIdempotencyKey / payloadFingerprint创建调用方幂等键并稳定识别当前页面请求载荷。
resolveServiceOrigin把 API 基址解析为私有内容读取的同服务 Origin，不使用公开演示地址。

接入约束

  • 共享核心不读取 window、uni、Vuex 或环境变量，网络请求和文件打开由调用端注入。
  • 管理端从 src/chamber/shared 引入；UniApp 从 chamber/shared 引入。准备脚本会自动复制。
  • 共享校验用于前端即时反馈，后端仍是权限、状态机、幂等、配额和文件安全的唯一裁决者。
  • 远端品牌配置失败时使用中性默认值并保留可序列化错误，不阻断应用启动。
