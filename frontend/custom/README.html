FRONTEND OVERLAY

前端二开入口

CRMEB v6.0.0 的 UniApp 用户端与 Vue2 管理端 overlay。双品牌使用同一代码和租户配置，不复制两份应用。

项目首页前端规则PRD

目录

frontend/custom/
├── uniapp/        # H5 / 微信小程序 / App overlay（镜像 UniApp 工程根目录）
├── admin/         # Vue 2 + Vuex 3 + Element UI overlay（镜像 admin 工程根目录）
└── shared/        # 双端共享的租户品牌配置与 Vue2 薄适配器

隔离工作区

上游 backend/crmeb 保持只读。准备脚本将 CRMEB v6.0.0 两套前端复制到被 Git 忽略的 .build-workspace/frontend，再叠加本目录代码。

./scripts/prepare-local-frontend.sh prepare
./scripts/prepare-local-frontend.sh check
./scripts/prepare-local-frontend.sh test
./scripts/prepare-local-frontend.sh build-admin

build-admin 固定执行“准备隔离副本 → npm ci → 生产构建”，并校验构建前后 package-lock.json 与 CRMEB 上游一致。依赖安装在 .build-workspace/frontend/admin/node_modules，产物位于 .build-workspace/frontend/admin/dist；两者均被 Git 忽略。

管理端声明 Vue ^2.5.10，CRMEB v6.0.0 锁文件实际解析为 Vue/Vue Template Compiler 2.7.16、Vuex 3.6.2、Vue CLI Service 3.12.1；Node 要求为 >14 <23。UniApp 当前没有 npm scripts/依赖声明，其旧锁文件也与 package 元数据不一致，按 HBuilderX/UniApp 工程构建。

实施规则

  • 先读取 TenantContext 和品牌配置，页面不硬编码渠道名、主色、客服码和协议。
  • 遵循上游 Vue2 Options API；不引入仅支持 Vue3 的组件、Pinia 或构建配置。
  • 所有业务状态以后端权限与状态机为准，前端隐藏按钮不代替服务端鉴权。
  • 小程序不使用 iframe；外部工具使用白名单 web-view，H5 支持发布会降级。
  • 新增管理页同步提交菜单、路由、API 权限、空/加载/错误/无权状态。
  • 会员长列表分页，隐私字段只渲染服务端已过滤结果。
