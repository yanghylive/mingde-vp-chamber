## 二、只能你在微信后台确认（我碰不到）

按驳回风险排序：

- [ ] **隐私保护指引**（高危）：`getPhoneNumber` 在用。后台需配置《隐私保护指引》并声明收集「手机号」用途，否则点授权会失败或被判 2.1。
- [ ] **服务类目**（高危）：当前含课程包售卖 + 会员付费。若类目选「教育-培训机构」被驳回，考虑改为「工具/会员服务」并把课程下架（`chamber.event` 已可按租户关课程包）。
- [ ] **版本描述**：如实写「修复页面加载问题」，不要写「新增分账」等未上线功能。
- [ ] **测试账号**（若需登录才能看某些页）：准备一个可用微信账号并在备注里给审核员。个人中心、我的报名等页需要登录。

## 三、真机回归（必做，我无法代替）

按这个顺序点，任何一页白屏/报错都先别提交：

1. **未登录**状态下依次点：首页 → 活动 → 商城 → 大咖 → 我的
   - 首页应能看到会员卡占位 + 精选活动（可能为空列表，不能是报错）
   - 大咖/商城应能看到真实数据（生产有阿曲 + 商品）
   - 我的 会跳登录页 —— **这是个人中心的行业惯例，若你担心被判「功能不完整」，可以改成登录前展示游客版个人中心**
2. 微信登录 → 应能拿到 token、进入个人中心
3. 会员中心 → 点「开通 L2」→ 应走虚拟支付流程（**不要真付**，验证到支付弹窗即可）
4. 活动详情 → 点报名 → 验证到下单页
5. 大咖详情 → 应能看到档期（若显示「暂无开放档期」是正常的，需要你在后台给大咖排一个档期才能演示预约）
