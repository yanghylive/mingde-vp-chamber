2. 端到端信任链

CRMEB api Token
  -> CrmebAuthTokenMiddleware
  -> TenantContextMiddleware
  -> ensureMemberInitialized
  -> GET/PATCH profile
  -> multipart upload private proof asset
  -> POST graduate-verifications
  -> CRMEB admin Token + chamber.graduate_verification.review
  -> admin list/detail/private content/review
  -> GET graduate-verifications returns approved + L2 projection
真实 HTTP 结果：本地门禁已完整通过用户资料查询/更新/幂等冲突、附件上传/重放/私有二进制读取、认证提交/查询、管理员列表/详情/材料读取/审核、审核重放与非法迁移拦截，并在结束后精确清理夹具。

用户端直接深链进入资料或认证页时，会先用当前 Token 幂等执行会员初始化。邀请参数只接受 8–16 位字母数字并暂存到本地；同一 Token 的并发初始化复用同一个 Promise，避免空邀请码与有效邀请码互相制造幂等冲突。会员退出或停用后，历史资料/审核幂等结果也不能绕过当前状态校验。

  • 当前数据库共 180 张表：157 张 CRMEB 原表、22 张 Chamber 领域表、1 张 ch_schema_migration。
  • ch_* 共 23 张，其中 22 张为领域/可靠性表，1 张为迁移登记表。

  • 上传文件位于被 Git 忽略的本地私有运行目录，数据库只保存受控对象键和校验元数据，不保存二进制。
  • 会员事务内限制 ready 材料 20 件/100 MiB、全部材料 200 件/512 MiB；达到上限即拒绝新上传。
  • ready 未提交材料对 Admin 返回 404；只有 consumed 且出现在指定申请不可变快照中的材料可读，read_asset 审计写入指定申请。
  • 读取或 approve 前发现对象缺失、大小或 SHA-256 不符时持久化为 unavailable；列表仍可展示元数据，退回/拒绝可继续，但 approve 返回 proof_asset_invalid 且不写通过审计或幂等结果。

7. 生产上线前必须完成

结论边界：G1-01C 已达到本地开发验收，不等于生产上线就绪。以下事项未完成，不能在发布材料中写成已具备。
  • 恶意文件防护：当前已有 MIME/签名/大小/哈希、图片尺寸/像素限制和 PDF 活动内容拒绝，但仍不能替代专业恶意软件扫描；病毒扫描、隔离区和放行流程是生产硬门槛。
  • 敏感访问审计：运营读取材料和审核决定已有追加审计；用户自读审计、异常告警、审计检索/导出和留存策略尚未完成。
  • 生产对象存储：当前为本地私有文件系统；生产私有 Bucket、KMS/服务端加密、短时授权、备份、跨节点一致性和密钥轮换尚未实现。
  • 生命周期治理：会员事务配额已执行；材料保留期限、撤回/注销后的删除、孤儿回收、系统级容量和监控告警仍需合规与运维确认。
  • 生产配置与验收：正式协议、隐私政策、运营账号/角色、域名、对象存储、监控、备份恢复和安全测试必须在上线门禁前提供并验证。
