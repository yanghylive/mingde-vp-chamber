2. 推荐启动方式

# 首次或确保数据库已安装
./scripts/prepare-local-crmeb-runtime.sh install

# 日常启动
./scripts/prepare-local-crmeb-runtime.sh start

访问地址：http://localhost:8011。运行源码位于 .build-workspace/crmeb-runtime，本地数据位于 deployment/local/.data。
