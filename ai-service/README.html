安全契约

  • 客户端不持有模型 API Key；CRMEB 签发有效期不超过 5 分钟的服务令牌。
  • 令牌声明包含 uid、tenant_id、membership、scopes、quota 和 jti。
  • 只通过 CRMEB Chamber API/OutAPI 读写业务，写工具必须二次确认和 Idempotency-Key。
  • 会员证明、手机号、支付参数和咨询隐私默认不进入模型上下文。
  • 所有工具调用记录租户、主体、助手、工具、参数摘要、结果、延迟和错误。
  • 模型失败、限流或余额不足时必须降级，不阻塞支付、报名和订单主链路。

首发工具范围
