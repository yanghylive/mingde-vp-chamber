完整门禁会安装或复用隔离运行副本、执行迁移与种子校验、运行 PHP/前端/OpenAPI 测试，并检查真实 HTTP Token、租户解析、同/不同 Key 并发、跨租户隔离、退出态重放拦截和 CORS。

不可破坏的规则

  • Controller 只处理参数、权限和响应，不直接查库。
  • 跨表写入进入 Services 事务，关键资源同时加 Redis/数据库锁。
  • 私域 Dao 必须显式带 TenantContext，禁止信任客户端传入的 tenant_id。
  • 会籍不复用 eb_user.level，好友不复用推荐关系，活动不复用秒杀 store_activity。
  • 迁移不修改 CRMEB 安装 SQL，表名统一 ch_ 前缀。
  • 金额用 decimal 字符串 + BCMath，积分、贡献值、分账和退款用追加账本。
  • CRMEB 支付/退款事件只作加速信号；统一事件必须先落持久化 inbox，退款受理不得冒充资金完成。

提交单个功能的最小产物

路由、中间件/权限、Controller、Services、Dao/Model、迁移、事件/队列（如有）、单元与 API 测试、OpenAPI 和 HTML 文档必须同时可评审。
