LOCAL DEVELOPMENT

本地 CRMEB Docker 环境

用于在 Mac 上运行 CRMEB 后端、Nginx、MySQL 和 Redis。运行数据保存在 deployment/local/.data，不进入 Git。

项目首页开工基线

启动命令

docker compose -f deployment/local/docker-compose.crmeb.yml up -d

启动后访问 http://localhost:8011。MySQL 端口为 33061，Redis 端口为 63791。

停止命令

docker compose -f deployment/local/docker-compose.crmeb.yml down

边界

  • 本 compose 不写入 CRMEB 官方 docker 目录，避免污染子模块。
  • PHP 容器挂载 backend/crmeb/crmeb，运行时目录和上传目录由本地数据卷覆盖。
  • 本地账号密码仅用于开发环境，生产环境另走部署配置。
