本地 CRMEB Docker 环境

用于在 Mac 上运行 CRMEB 后端、原生 timer、Nginx、MySQL 和 Redis。源码与商会 overlay 同步到隔离运行副本，安装配置和运行数据都不进入 Git。

项目首页 开工基线 数据库迁移 TenantContext

首次准备

./scripts/prepare-local-crmeb-runtime.sh install
./scripts/manage-local-database.sh setup

第一条命令准备运行副本、启动五个容器（MySQL、Redis、PHP-FPM、CRMEB timer、Nginx）、等待 MySQL/Redis、完整导入 CRMEB 157 张基线表、同步商会 overlay 并锁定安装器；第二条命令执行商会迁移、本地通用种子和数据校验。当前结果为 187 张表、463 项迁移复验。默认后台账号为 admin，密码为 Admin@123456，仅供本机开发。

日常启动

./scripts/prepare-local-crmeb-runtime.sh start
./scripts/prepare-local-crmeb-runtime.sh status
./scripts/manage-local-database.sh status

应用入口为 http://localhost:8011，MySQL 端口为 33061，Redis 端口为 63791；公开端口只绑定本机回环地址。PHP-FPM、timer 和 40001/40002 WebSocket 端口仅在 Docker 内网可达。timer 使用 CRMEB 原生调度器，每分钟批量补绑未完成的会籍 OrderContext；数据库 setup 会重启本地 timer，使新注册任务重新加载。公开 API 与根进程的 CRMEB 订单/商品行/退款/收货服务均经过 Chamber 守卫，可信会籍网关使用受控 DAO。每次启动都会把当前上游源码和 backend/custom/app/chamber 同步到隔离运行副本。

覆盖本地参数

CRMEB_LOCAL_ADMIN_PASSWORD='你的本地密码' \
CHAMBER_TENANT_SIGNING_SECRET='至少32字节的本地密钥' \
CHAMBER_IDEMPOTENCY_ENCRYPTION_KEY='至少32字节的本地密封密钥' \
CHAMBER_CORS_ALLOWED_ORIGINS='http://localhost:5173' \
CRMEB_HTTP_PORT=8011 \
./scripts/prepare-local-crmeb-runtime.sh install

还可设置 CRMEB_DB_USER、CRMEB_DB_PASSWORD、CRMEB_DB_NAME、CRMEB_REDIS_PASSWORD、CHAMBER_DEV_TENANT_SLUG 和 CHAMBER_DEV_CHANNEL_CODE。CORS 只接受精确 Origin，不支持通配符。同一套参数应贯穿首次安装和后续启动；签名与幂等密封默认值只允许本机使用。

停止命令

docker compose -f deployment/local/docker-compose.crmeb.yml down

该命令保留数据库。需要清空本地环境时，应先停止容器，再人工删除 deployment/local/.data 与 .build-workspace/crmeb-runtime；这是破坏性操作，不由脚本自动执行。

隔离边界

  • 上游源码固定在 backend/crmeb 子模块，容器不会直接挂载它。
  • 可执行副本位于 .build-workspace/crmeb-runtime；重新同步时会保留 .env、.constant 和 public/install.lock。
  • 数据库、Redis、日志、运行时和上传文件位于 deployment/local/.data；私有材料权限受限，不提供 Nginx 静态公开目录。
  • 数据库初始化只对空库执行，发现已有表时不会覆盖数据。
  • 默认密码仅用于本地开发；生产环境必须使用独立密钥与部署配置。
生产边界：本地驱动已有配额、JPEG/PNG 内容级限制、历史 PDF 只读、完整性校验和读取审计，但专业恶意软件扫描仍是生产硬门槛。生产必须切换私有对象存储并完成 KMS/加密、生命周期、审计告警/检索、容量监控、备份恢复和密钥轮换。
