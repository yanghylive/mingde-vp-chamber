本地 CRMEB Docker 环境

用于在 Mac 上运行 CRMEB 后端、Nginx、MySQL 和 Redis。源码与商会 overlay 同步到隔离运行副本，安装配置和运行数据都不进入 Git。

项目首页 开工基线 数据库迁移 TenantContext

首次准备

./scripts/prepare-local-crmeb-runtime.sh install
./scripts/manage-local-database.sh setup

第一条命令准备运行副本、启动容器、等待 MySQL/Redis、安装 CRMEB、同步商会 overlay 并锁定安装器；第二条命令执行商会迁移、本地通用种子和数据校验。默认后台账号为 admin，密码为 Admin@123456，仅供本机开发。

日常启动

./scripts/prepare-local-crmeb-runtime.sh start
./scripts/prepare-local-crmeb-runtime.sh status
./scripts/manage-local-database.sh status

应用入口为 http://localhost:8011，MySQL 端口为 33061，Redis 端口为 63791；三者只绑定本机回环地址。PHP-FPM 和 40001/40002 WebSocket 端口仅在 Docker 内网可达。每次启动都会把当前上游源码和 backend/custom/app/chamber 同步到隔离运行副本。

商会接口

地址用途租户要求
http://localhost:8011/chamber/health运行探针与链路标识无
http://localhost:8011/chamber/v1/bootstrap返回可信的租户、渠道和解析来源本地默认映射到 local-primary/default

完整验收

./scripts/check-g0-baseline.sh

门禁覆盖项目结构、Compose 配置、CRMEB 安装、迁移校验和、种子数据、PHP 测试、前端共享逻辑、OpenAPI 以及真实 HTTP 的 Host/HMAC 租户解析、重放拒绝和 CORS。

覆盖本地参数

CRMEB_LOCAL_ADMIN_PASSWORD='你的本地密码' \
CHAMBER_TENANT_SIGNING_SECRET='至少32字节的本地密钥' \
CHAMBER_CORS_ALLOWED_ORIGINS='http://localhost:5173' \
CRMEB_HTTP_PORT=8011 \
./scripts/prepare-local-crmeb-runtime.sh install

还可设置 CRMEB_DB_USER、CRMEB_DB_PASSWORD、CRMEB_DB_NAME、CRMEB_REDIS_PASSWORD、CHAMBER_DEV_TENANT_SLUG 和 CHAMBER_DEV_CHANNEL_CODE。CORS 只接受 CHAMBER_CORS_ALLOWED_ORIGINS 中以逗号分隔的精确 Origin，不支持通配符。同一套参数应贯穿首次安装和后续启动；签名密钥默认值只允许本机使用。

停止命令

docker compose -f deployment/local/docker-compose.crmeb.yml down

该命令保留数据库。需要清空本地环境时，应先停止容器，再人工删除 deployment/local/.data 与 .build-workspace/crmeb-runtime；这是破坏性操作，不由脚本自动执行。

隔离边界

  • 上游源码固定在 backend/crmeb 子模块，容器不会直接挂载它。
  • 可执行副本位于 .build-workspace/crmeb-runtime；重新同步时会保留 .env、.constant 和 public/install.lock。
  • 数据库、Redis、日志、运行时和上传文件位于 deployment/local/.data。
  • 数据库初始化只对空库执行，发现已有表时不会覆盖数据。
  • 默认密码仅用于本地开发；生产环境必须使用独立密钥与部署配置。
