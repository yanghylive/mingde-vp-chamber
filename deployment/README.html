发布规则

  • 产物必须从固定的父仓库 SHA + CRMEB 子模块 SHA 构建，不在生产服务器现场改代码。
  • 每次发布生成 manifest，记录源码、镜像摘要、迁移版本、前端包和配置版本。
  • 数据库使用 expand/contract 迁移；账本和支付数据不做破坏性回滚。
  • 密钥进入密钥管理服务，日志不输出 Token、支付参数和证明材料 URL。
  • 禁用 CRMEB 后台在线升级功能直接覆盖生产代码。
